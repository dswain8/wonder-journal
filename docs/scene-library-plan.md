# Wonder Journal Scene Library Plan

This document defines the first reusable scene library for Wonder Journal.

The goal is not to gather lots of random pictures.
The goal is to build a small, coherent set of reusable scenes that make the product feel consistent and premium.

## 1. Principle

Build scenes, not categories.

Weak approach:

- `space`
- `animals`
- `weather`

Better approach:

- `night-drive-moon`
- `rainy-peacock-field`
- `sunny-garden-butterfly`

Questions are specific. The image system should be specific too.

## 2. V1 Art Direction

The first image library should follow one visual system:

- picture-book style
- warm, rounded shapes
- calm premium palette
- consistent character proportions
- no hard realism
- no visual clutter

Recommended framing:

- square or portrait-first scenes
- one clear focal action
- enough negative space for overlays

## 3. Scene Metadata Model

Each scene should eventually have:

- `slug`
- `topic`
- `scene_tags`
- `visual_anchor`
- `mood`
- `question_matches`
- `notes`

## 4. Target Count

V1 should start with 30 scenes.

That is enough to make the product feel rich without creating an impossible content burden.

## 6. Reuse Strategy

Each scene should be reusable across multiple closely related questions.

For example:

- `night-drive-moon`
  - moon follows car
  - why the moon stays in one place
  - why far things seem slower

- `sun-after-puddle`
  - where rain goes
  - evaporation
  - puddles drying up

This is how the library scales without needing thousands of assets.

## 7. Priority Order

Build scenes in this order:

### Tier 1

- `night-drive-moon`
- `rainy-peacock-field`
- `rooftop-star-watch`
- `breathing-diaphragm-hiccup`
- `sun-after-puddle`

### Tier 2

- `rainbow-over-grass`
- `autumn-tree-color-change`
- `playground-fast-heart`
- `butterfly-garden-closeup`
- `ice-cube-sun-puddle`

### Tier 3

- everything else in the initial 30-scene set

## 8. Recommendation

Do not try to source 150 unrelated images immediately.

Start with:

- 5 gold-standard scenes
- then 15 scenes
- then the full 30-scene v1 library

That will give Wonder Journal a more coherent product feel and make image matching dramatically easier.
